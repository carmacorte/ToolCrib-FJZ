ADMINISTRACIÓN LOCAL

Datos y respaldos

Administración de la base local y generación de Excel para gerencia, sin conexión.

Inicio limpio al abrir el HTML

Cada vez que se abre o actualiza este archivo, el inventario y los movimientos de la sesión anterior dejan de mostrarse. Antes de vaciar, se guarda una copia de recuperación local, pero el respaldo oficial sigue siendo el JSON descargado.

Inicio limpio activo.

Revisando copia de recuperación...

Atención: si actualizas la pestaña con F5 también se considera una nueva apertura. Para operaciones reales, descarga el JSON al cierre del turno. Un Excel gerencial no contiene un historial restaurable completo.

Importar Excel actualizado

Abre la última copia de inventario en .xlsx, CSV o Excel HTML (.xls). El sistema detecta SKU nuevos y compara los existentes para sincronizar stock, mínimos, máximos y datos del material, sin eliminar el historial local.

Antes de aplicar cambios muestra una vista previa. Un ajuste de existencia genera un movimiento auditable. No importa el historial desde el reporte Excel: usa el respaldo JSON para restauración completa.

Reportes Excel para gerencia

Genera un libro Excel real con Resumen ejecutivo, Inventario, Reabastecimiento, Movimientos Indicadores por BU y Tendencia de movimientos. Incluye estados, costos, prioridades y cálculos para resurtido.

Última importación: no registrada.

Respaldo completo

Guarda el inventario, configuración y todos los movimientos en un respaldo JSON. Hazlo al cierre de cada turno o jornada: el almacenamiento local no reemplaza una copia de seguridad.

Restaurar reemplaza la base local actual, previa confirmación. El catálogo de equipos ya está integrado en este HTML.

Entorno de demostración

Carga algunos materiales de ejemplo para probar niveles de stock y movimientos. Los ejemplos se identifican como DEMO y pueden eliminarse después.

Sin registros de prueba.

Uso en planta y controles

Este HTML está diseñado para una sola computadora. No requiere internet ni servidor. La base operativa vive en el navegador, pero con Inicio limpio activo se vacía al abrir o actualizar este HTML. No borres datos del sitio ni abras modo privado: también podrías perder la recuperación temporal. Los reportes Excel son copias de consulta y pueden sincronizarse con vista previa.

Operación recomendada: al abrir, importar el Excel actualizado o restaurar el JSON; registrar entradas/salidas, exportar Excel para gerencia y descargar el respaldo JSON antes de cerrar. Usa siempre el mismo navegador y archivo HTML.
