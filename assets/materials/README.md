# Fotografías de refacciones

Usar una carpeta por SKU, por ejemplo `assets/materials/TC-NOZZLE-501/main.webp`.
Se recomienda `main.webp`, `side.webp` y `label.webp`.
El nombre debe coincidir con el SKU del Excel (sin diferencias de mayúsculas).
Actualizar `data/materials-images.json` para declarar imágenes.
Usar exclusivamente fotografías reales verificadas u oficiales autorizadas.
No subir información interna sin aprobación de IT.
